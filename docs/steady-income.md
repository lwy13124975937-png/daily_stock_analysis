# 稳健收益模块

## 定位

“稳健收益”用于检查当前 A 股持仓是否具备低风险、可持续现金分红和长期总回报基础。它是规则筛选工具，不调用 LLM，也不预测短期涨跌。

模块坚持两个顺序：

1. 先用现金流、盈利、回撤、波动和分红连续性做风险硬门槛。
2. 只在同一风险层内比较股息率、分红可持续性和历史稳定性。

高股息不能覆盖负经营现金流、亏损、巨幅回撤或分红中断。页面没有“直接买入”结论。

## 数据范围

- 标的范围：当前持仓中的沪深北 A 股股票；港股、美股、B 股、指数、债券、ETF、LOF 和其他基金不纳入。
- 分红：近 12 个月税前每股现金分红及 TTM 税前股息率。
- 可持续性：连续现金分红年数、归母净利润、经营现金流及两者覆盖关系。
- 风险：约七年日线计算的年化波动率和最大回撤。
- 历史回放：最近五个完整年度末之间的前复权总回报；以前一完整年度末为基准，避免漏掉跨年价格变化。前复权行情已经反映分红和拆并股影响，不再重复加现金分红。
- 估值辅助：PE、PB、ROE；它们不会绕过风险硬门槛。

模块不向 Web 返回持仓数量、成本、市值或盈亏。

连续分红只统计评估基准日之前、每股现金分红大于零的事件。股息率按 TTM 每股现金分红和页面所示当前行情价格重新计算，避免价格与股息率来自不同时间点。

## 风险层级

| 层级 | 含义 |
| --- | --- |
| 稳健 | 分红、现金流、回撤、波动和五期回放均通过较严格门槛 |
| 较稳健 | 通过次一级门槛，但稳定证据弱于“稳健” |
| 观察 | 没有触发一票否决，但尚未满足低风险候选门槛 |
| 不纳入 | 触发高股息陷阱、亏损、负经营现金流、过高回撤/波动等硬风险 |
| 数据不足 | 缺少分红、财务或长期行情，不能可靠判断 |

页面展示的“同层规则分”只负责同层排序，不代表预期收益率，也不能把“观察”或“不纳入”提升为低风险候选。

## 股息率价格带

页面按当前 TTM 每股现金分红反推三档价格：

- 高股息观察价：约 5% TTM 股息率。
- 平衡观察价：约 3.5% TTM 股息率。
- 低收益上沿：约 2.5% TTM 股息率。

价格带只说明分红收益率和价格的关系，不考虑未来分红变化，也不是买入价承诺。

## 使用入口

- Web：侧栏 `稳健收益`，路由 `/steady-income`。
- API：`GET /api/v1/steady-income/portfolio`。
- `refresh=true` 可绕过六小时进程内缓存，重新读取公开行情与财务数据。

单只股票的数据源失败只会把该标的降为“数据不足”，不会把其他标的伪装成合格结果。

模块不会为了缩短运行时间静默截断持仓列表。负债结构、未来派息政策与特别分红不属于当前标准化数据硬门槛；这些信息缺失时，页面不会把它们推断为安全。

## 回滚

删除该模块只需回退后端服务、API endpoint/schema/router、Web 页面/API/类型/导航、测试与本文档。不会影响原有 A 股分析、持仓核算、回测、告警或 LLM 配置。
