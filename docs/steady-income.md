# 稳健收益模块

## 定位

“稳健收益”用于从全部沪深 A 股中筛选具备较低风险、可持续现金分红和长期总回报基础的候选。它独立于当前持仓，是规则筛选工具，不调用 LLM，也不预测短期涨跌。

模块坚持两个顺序：

1. 先用现金流、盈利、回撤、波动和分红连续性做风险硬门槛。
2. 只在同一风险层内比较股息率、分红可持续性和历史稳定性。

高股息不能覆盖负经营现金流、亏损、巨幅回撤或分红中断。页面没有“直接买入”结论。

## 数据范围

- 标的范围：股票索引中的全部活跃沪深 A 股；北交所、港股、美股、B 股、指数、债券、ETF、LOF 和其他基金不纳入。
- 两阶段筛选：先对全市场逐只应用年度现金分红、盈利、支付率、上市年限、ST/退市风险和历史分红次数预筛；再对预筛排名靠前的有限候选抓取长期行情、现金流和分红明细进行深度风险评估。
- 分红：近 12 个月税前每股现金分红及 TTM 税前股息率。
- 可持续性：连续现金分红年数、归母净利润、经营现金流及两者覆盖关系。
- 风险：约七年日线计算的年化波动率和最大回撤。
- 历史回放：最近五个完整年度末之间的前复权总回报；以前一完整年度末为基准，避免漏掉跨年价格变化。前复权行情已经反映分红和拆并股影响，不再重复加现金分红。
- 估值辅助：PE、PB、ROE；它们不会绕过风险硬门槛。

模块不读取当前持仓作为候选范围，也不输出账户、持仓数量、成本、市值或盈亏。

连续分红只统计评估基准日之前、每股现金分红大于零的事件。股息率按 TTM 每股现金分红和页面所示当前行情价格重新计算，避免价格与股息率来自不同时间点。

## 风险层级

| 层级 | 含义 |
| --- | --- |
| 稳健 | 分红、现金流、回撤、波动和五期回放均通过较严格门槛 |
| 较稳健 | 通过次一级门槛，但稳定证据弱于“稳健” |
| 观察 | 没有触发一票否决，但尚未满足低风险候选门槛 |
| 不纳入 | 触发高股息陷阱、亏损、负经营现金流、过高回撤/波动等硬风险 |
| 数据不足 | 缺少分红、财务或长期行情，不能可靠判断 |

页面展示的“同层规则分”只负责同层排序，不代表预期收益率，也不能把“观察”或“不纳入”提升为低风险候选。

## 股息率价格带

页面按当前 TTM 每股现金分红反推三档价格：

- 高股息观察价：约 5% TTM 股息率。
- 平衡观察价：约 3.5% TTM 股息率。
- 低收益上沿：约 2.5% TTM 股息率。

价格带只说明分红收益率和价格的关系，不考虑未来分红变化，也不是买入价承诺。

## 使用入口

- GitHub Pages：首页报告中心的 `稳健收益`，静态页面 `steady_income.html`。
- 数据文件：`site/data/steady_income.json`，包含全市场覆盖数、预筛数、深评数和合格数，便于核验筛选漏斗。

登录态 Web 中原有的当前持仓检查保留，但导航和页面名称改为 `持仓稳健性`，不再与全市场 `稳健收益` 混用概念。

每日分析 workflow 运行 `scripts/build_steady_income_report.py`。脚本读取公开沪深股票索引、年度分红方案和历史分红汇总，完成全市场预筛后，再复用风险硬门槛生成 `site_data/steady_income.json`；随后 `scripts/build_pages_report.py` 生成静态页面。此过程不读取持仓快照，不调用 LLM。若股票池小于合理的沪深全市场规模、筛选漏斗数量矛盾或页面退回“当前持仓”口径，HTML 检查会阻止 Pages 部署。

单只股票的数据源失败只会把该标的降为“数据不足”，不会把其他标的伪装成合格结果。

全市场每只股票都会进入基础预筛；深度评估数量有公开上限，页面会同时展示全市场覆盖数、预筛合格数与深评数，不把有限深评伪装成全量逐只深评。负债结构、未来派息政策与特别分红不属于当前标准化数据硬门槛；这些信息缺失时，页面不会把它们推断为安全。

## 回滚

删除 Pages 全市场筛选只需回退 `scripts/build_steady_income_report.py`、`scripts/build_pages_report.py`、`scripts/check_report_html.py`、workflow 步骤、测试与本文档。不会影响原有 A 股分析、持仓核算、回测、告警或 LLM 配置。
