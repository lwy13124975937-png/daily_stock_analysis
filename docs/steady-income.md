# 稳健收益模块

## 定位

“稳健收益”面向全部沪深 A 股，目标是在规则可验证、证据时点可信的前提下，先排除高风险和证据不足标的，再比较现金分红与历史稳定性。它不以当前持仓作为候选池，不调用 LLM，也不预测短期涨跌。

高股息不能覆盖亏损、负经营现金流、分红未实施、行情过期、回撤过大或证据缺失。页面中的 `规则低风险 A/B` 是规则筛选结果，不代表保本、确定收益或买入建议。

## 数据合同

- 范围：公开股票主数据中的活跃沪深 A 股；ETF、LOF、场外基金、债券、B 股、港美股和北交所不纳入。
- 分红：只统计评估基准日之前已经实施、具有有效除权除息日、每股现金分红大于零的事件。公告日不能代替现金分红实施日，同一实施事件会去重。
- 财务：证据同时记录报告期末和可获得时间。历史模式只允许 `available_at <= as_of` 的财务证据；Provider 没有披露时点、历史证券状态或 point-in-time 股票池时，历史模式拒绝运行，不以当前数据伪造无前视回测。
- 行业：行业来自标准证券主数据，不根据公司名称猜测。普通企业使用企业现金流模型；银行、保险、券商等金融行业只有在专用监管证据可得时才可评估，否则标记“行业模型证据不足”并排除。
- 行情：价格日期必须不晚于评估日，并与最近已完成的 A 股交易 session 一致；盘前和盘中不会把尚未收盘的当天误判为应有收盘价。历史完整性按交易所 session 数量和覆盖率判断。
- 复权语义：Provider 未证明 point-in-time 总回报口径前，公开页面只称“历史复权价格回放”，不宣称无前视总回报。

所有证据、规则和结果均携带 schema/model/evaluator/sector/evidence/price 版本；规则版本变化会使旧缓存失效。缺少可靠字段时显示“数据不足”，不补造数值。

## 筛选漏斗

1. 全市场执行低成本预筛，并记录各排除原因。
2. 按行业分层选择有限数量进入深度证据评估，生产结果使用明确的 `selection_mode`，深评预算可配置。
3. 页面和结构化数据同时公开 universe、预筛、深评预算、实际深评、未深评、合格数量及 `is_exhaustive`，不把有限 shortlist 描述成全市场全部通过深度验证。
4. shortlist 模式下 `qualified_count = 0` 只表示“本次已深度评估的候选中没有合格标的”；只有 `is_exhaustive=true` 才能表达全部预筛候选均已验证。数据源失败或 schema 变化则构建失败，不能伪装成零候选。

离线 selection sensitivity 会对 deep=30/60/120/240 比较严格队列前缀、候选召回、Top-3/5/10、预筛分数区分能力、Provider 调用和缓存命中；Provider 并发审计可固定同一批普通企业比较 workers=1/2/4/8。每个深评标的只有一个终态，完成评估等于规则合格与规则排除之和；证据不足、金融行业模型不支持、Provider 失败和内部错误分别统计。它不改变风险阈值，也不调用 LLM。

页面区分三种结论：全部请求均完成但无合格标的是合法零候选；部分请求完成时标为降级并显示完成比例；全部因 Provider 失败时显示数据源不可用，绝不把系统未完成评估描述成“没有合格标的”。

## 展示

- 默认页完整展示合格候选；排除和数据不足标的折叠为紧凑列表。
- `ranking_score` 仅在证据完整且可比较的集合中存在；旧 `score` 只是 deprecated 兼容别名。
- 默认页不展示“高股息观察价”或“股息率对应价格”。过去 TTM 分红反推价格不是内在价值或建议买价。
- 页面不公开账户、持仓数量、成本、持仓市值或盈亏。

## 构建与入口

- GitHub Pages：`steady_income.html`。
- 数据：`site/data/steady_income.json`。
- 登录态 Web 的当前持仓规则评估仍叫“持仓稳健性”，与全市场 Pages 模块分开。

`scripts/build_steady_income_report.py` 只生产版本化数据；`scripts/build_pages_report.py` 是站点唯一 owner。站点在全新 staging 目录生成并校验 manifest、hash、build_id、内链、安全 HTML 和跨数据集时点后，才以事务式 promotion 替换正式 `site/`；若校验或 promotion 失败，会保留上一份已验证站点。该模块不读取持仓作为候选池，也不调用 LLM。

## 当前限制

当前 Provider 若没有可验证的历史披露日期、历史上市/ST 状态或金融机构监管指标，相关 historical/金融行业结果会 fail closed 为 unavailable/数据不足。这是证据边界，不会通过假定日期或普通企业现金流模型绕过。
